## 1. 基本の流れ

1. **気付く**: 管理者へのメール（件名「【備品貸出】処理に失敗しました」の形）、処理ログの「失敗」、利用者からの連絡。
2. **範囲を決める**: どのフローの、どの記録か（処理ログの「件名」と「対象」）。
3. **実行の履歴を見る**: Power Automate でそのフローの実行の履歴を開き、赤い手順とエラーの文を確かめる。利用目的などは隠してあるため、中身は SharePoint のリストで確かめる。
4. **記録をそろえる**: 2章の表で、貸出記録・予約表・備品台帳を正しい状態に直す。
5. **原因を直す**: 3章の表。
6. **残す**: 処理ログの該当行の「詳細」に、何をしたかを追記する。

## 2. 記録の食い違いの直し方

| 見つけた状態 | 直し方 |
|---|---|
| 貸出記録が「確認中」のまま | 1時間たてば FLW-003 が翌朝「エラー」にする。急ぐ場合は手で「エラー」にし、予約表の同じ件名の行を消す |
| 貸出記録が「承認待ち」なのに承認依頼が無い | 承認開始日時が空なら、FLW-002 がオンか確かめる（オンなら1分以内に動く）。入っているのに依頼が無ければ、記録を「期限切れ」にし、予約表の行を消し、申請者にもう一度申請してもらう |
| 貸出記録と予約表の状態が違う | 貸出記録を正とし、予約表の行の状態を合わせる（終わった記録の行は消す） |
| 備品台帳が「修理中」のまま | 故障報告で、その備品の「修理中」の報告が残っていないか確かめる。残っていなければ、どれかの報告の対応状況を保存し直す（FLW-006 がそろえる） |
| Planner のタスクと故障報告の対応状況が違う | 故障報告を正とする。故障報告の対応状況を保存し直すと、タスクが合う |
| 同じ回答で故障報告が2件 | 片方を「対象外」にする |

## 3. 症状別の原因と対応

| 症状 | 主な原因 | 対応 |
|---|---|---|
| アプリで「利用者を確認できませんでした。会社のアカウントで…」 | フローが要求ヘッダーのメールアドレスを受け取れていない | 利用者に会社のアカウントでアプリを開き直してもらう。続く場合は FLW-001 の実行の履歴でトリガーの状態を確かめる |
| アプリで「利用者を確認できませんでした。管理者に連絡…」 | アカウントのメールと UPN の両方が、SharePoint のユーザーと一致しない | Microsoft 365 管理センターで利用者のメールアドレス・UPN を確かめる |
| アプリで「処理に失敗しました。…」 | FLW-001 の失敗（接続切れ・リストの列の変更など） | 処理ログと実行の履歴で失敗した手順を確かめる。接続切れなら 3.1 |
| 承認されたのに状態が変わらない | 承認の前に取り消された（結果を書かない仕様）、または FLW-002 の失敗 | 貸出記録の状態と処理ログを確かめる |
| 督促・お知らせが届かない | FLW-003 が止まっている、または同じ日に送り済み（最終通知日） | フローがオンか、最終通知日を確かめる |
| 故障の報告が Planner に出ない | FLW-004 の失敗、フォームの ID・質問の ID の変更 | 実行の履歴を確かめる。フォームを作り直した場合は 2.4（06）で FORM_ID・Q_CODE・Q_DETAIL を直して作り直す |
| 月次の CSV が無い | FLW-005 の失敗 | 詳細画面の「実行」で手動で動かす（同じ月は上書き） |
| どのフローも動かない | 所有者のアカウントの無効化、接続の期限切れ、フローの停止 | 3.1 |
| 処理ログに「失敗」で、実行の履歴の書き込みの手順が状態コード 412 | ETag が合わなかった（別の処理が先に変えた） | 記録の今の状態を見て、2章で必要ならそろえる。自動ではやり直さない |

### 3.1 接続・フローの停止

1. Power Automate の「マイ フロー」で6本がオンか確かめる。オフならオンにする。
2. 「データ」→「接続」で、エラーの表示がある接続を開き、「接続の修正」でサインインし直す。
3. 所有者が異動・退職した場合は、06 の6章の手順で接続を付け替える。

## 4. 連絡

| 状況 | 誰へ | 何を伝える |
|---|---|---|
| 利用者の申請が失敗した | 申請者 | もう一度申請してよいか、直るまで待つか |
| 承認の途中で止まった | 申請者・承認者 | 申請は無効になったため、もう一度申請してほしい |
| 半日以上フローが止まった | 社員全体（チャンネル） | 止まっていた期間と、その間の申請の扱い |
